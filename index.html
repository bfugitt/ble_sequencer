Step Sequencer

Click squares to build a pattern, then press Play. Each row is a note and each column is one step in time. The space bar also starts and stops.

Notes

Changing the scale keeps your pattern but changes which notes it plays.

Where the sound goes

Playing through this computer's speaker. Press Connect to send notes to a synth.

Synth not showing up?
  • Use Chrome or Edge. Safari does not support Web MIDI.
  • Chromebook or Bluetooth synth: use Connect Bluetooth MIDI. It talks to the synth directly, so it works even when the computer does not list the synth as a MIDI device. Do not pair the synth in the computer's Bluetooth settings first: many synths then show up as a Bluetooth speaker, and the computer's sound plays through them instead of MIDI notes. If it is already paired there, remove it, and make sure no other device (a phone, or another browser tab) is connected to it.
  • "Midi Through" is a loopback inside the computer. It goes nowhere, so it is hidden from the list.
  • A USB cable from the synth to the computer also works on a Chromebook.
  • Turn the synth on first, then press Connect and allow the MIDI permission.
  • USB-connected synths show up on most computers. For Bluetooth, pair the synth with the computer first (on a Mac, use Audio MIDI Setup, then Bluetooth). Some systems do not share Bluetooth MIDI devices with the browser.
  • Connected but silent? Make sure the MIDI channel matches the synth. Try channel 1, then 2.
  • Patch number sends a Program Change message. Not every synth responds to it.

MIDI messages

Every note is a short message: a status byte (what to do, and on which channel), a note number, and a velocity (how hard). A synth receives these same bytes over USB or Bluetooth. Messages show here even when you are using the built-in sound.

Press Play to see messages.
